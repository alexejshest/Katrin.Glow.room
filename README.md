# Katrin Glow Room — сайт визажиста (Батуми)

Лендинг с онлайн-записью: свадебный и вечерний макияж, образ в 4 руки, курс «Макияж для себя». RU / EN.

Открывается без сборки: `index.html` (или любой статический сервер, например `python3 -m http.server`).

## Структура
- `index.html`, `css/style.css`
- `js/config.js` — цены, адрес, Instagram, настройки Telegram
- `js/booking.js` — календарь, слоты, запись
- `js/i18n.js` — переводы, `js/sound.js` — звуки, `js/fx.js`, `js/falling.js` — эффекты
- `img/`, `video/` — демо-материалы (источники в `img/CREDITS.md`)

## Telegram
**Токен бота нельзя хранить в этом репозитории**: сайт публичный, и токен прочитает любой.
Пока в `config.js` стоят заглушки, сайт работает в демо-режиме. Для реальных заявок нужен серверный посредник
(токен хранится в его секретах).

## Ограничения
Занятость слотов хранится в браузере посетителя, пока нет общего сервера.
